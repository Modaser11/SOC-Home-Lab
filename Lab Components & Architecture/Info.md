To build this SOC Home Lab, we will deploy three core components:

1.Victim Machine (Windows 10)
  Acts as the primary target for executing attack scenarios, generating system logs, and simulating endpoint activity.

2.Attacker Machine (Kali Linux)
  Used to perform reconnaissance, exploitation, and post-exploitation attacks against the victim machine.

3.SIEM Server (Splunk Enterprise on Ubuntu LTS)
  Deployed on an Ubuntu LTS server to ingest, analyze, and visualize logs collected from the environment for threat detection and investigation.
